# Démarrage rapide

1. Dans Claude Code, ouvre le repo **`caisse`**.
2. Envoie ce zip dans la discussion avec le message suivant :

```
Décompresse ce zip à la racine du repo caisse (CLAUDE.md et le dossier legacy/ doivent être à la racine), commite, puis lis CLAUDE.md en entier, regarde les photos de legacy/photos/, pose-moi les questions de la section 20 et démarre la Phase 0.
```

C'est tout. Claude Code te posera ensuite ses questions (papier 80 ou 58 mm, accès Internet de la caisse, etc.).

## Contenu
- `CLAUDE.md` — le cahier des charges complet que Claude Code relit à chaque session.
- `legacy/` — l'ancienne version de l'app, le premier jet du site, l'ancienne passerelle, les photos (carte, imprimante, caisse) et les captures des bugs.
